# MakSy School — fichiers d'installation

MakSy School (anciennement « Kalan ») est un logiciel de gestion
d'établissement scolaire : élèves, inscriptions, frais de scolarité, notes et
bulletins, absences, documents.

Ce dépôt ne contient **que les fichiers d'installation** de MakSy School. Il
n'y a ici ni code source, ni donnée d'aucune école.

## À quoi sert ce dépôt

Le MakSy School installé dans une école vient y vérifier, quand son poste a
Internet, s'il existe une version plus récente. Il ne télécharge et n'installe
rien sans l'accord du directeur.

## Installer MakSy School

1. Ouvrez la page [Releases](../../releases/latest).
2. Téléchargez le fichier `MakSy-School-Installation-<version>.exe`.
3. Lancez-le sur l'ordinateur qui servira de poste maître (Windows 10 ou 11).

Windows affichera « éditeur inconnu » : le fichier n'est pas signé.

MakSy School fonctionne soixante jours sans clé d'activation. Passé ce délai,
la saisie est suspendue ; la consultation, l'impression et l'export restent
possibles et aucune donnée n'est effacée. La clé d'activation est remise par
le fournisseur.

## Vous aviez Kalan

Fermez Kalan (« Quitter Kalan » près de l'horloge), puis installez MakSy
School : il remplace Kalan et reprend ses données au premier lancement, sans
modifier l'ancien dossier. Les clés d'activation déjà remises restent valables.
